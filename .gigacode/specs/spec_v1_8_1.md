## 🐞 Этап 3.1. Статистика раунда

### 🎯 Цель

Экран результатов показывает **фактическое** число правильных и неправильных ответов, а
оценка считается **от них**. Очки, жизни, пороги оценок и остальной геймплей **не меняются**.

### 🐞 Дефект 1.8.0

**Воспроизведение.** Раунд из 10 вопросов: 8 правильных, 2 неправильных, жизни > 0,
раунд завершён.

| Показатель | 1.8.0 (факт) | 1.8.1 (ожидание) |
|---|---|---|
| `correct` | **10** | **8** |
| `wrong` | **10** | **2** |
| `total` | 10 | 10 |
| `roundScore` | 80 | 80 |
| Оценка | 🏆 «Идеально!» (100%) | 🎉 «Отлично!» (80%) |
| «Правильных» на экране | 10 | 8 |

**Причина.** Результат собирался из **индекса вопроса**, а не из ответов: к концу раунда
индекс равен 10, поэтому `correct = 10`, а `wrong` копировал `correct` (10). Точность всегда
100%, и любой завершённый раунд получал «Идеально!». Счётчиков правильных и неправильных
ответов в модели раунда не было.

**Досрочное окончание** (0 жизней). В 1.8.0 при 0/3: `correct = 3`, `wrong = 3`,
`total = 10`, оценка «Игра окончена». Оценка верная, статистика — нет.

### 📋 Технические требования

#### TR-23. Считать ответы в момент ответа

**Требование.** Модель раунда ведёт два счётчика: правильные и неправильные ответы.

- правильный ответ: счётчик правильных +1, `roundScore += POINTS_BASE`;
- неправильный: счётчик неправильных +1, `lives -= 1`;
- счётчики меняются **только** при ответе и не зависят от индекса вопроса, очков и жизней.

**Критерий готовности:** после 8 правильных и 2 неправильных счётчики равны 8 и 2.

---

#### TR-24. Результат раунда — фактические ответы

**Требование.** `getResults()` возвращает реальные значения.

| Поле | Значение |
|---|---|
| `correct` | число правильных ответов |
| `wrong` | число неправильных ответов |
| `total` | `correct + wrong` — **фактически отвечено** |
| `roundScore` | накопленные очки раунда |
| `lives` | текущие жизни |
| `completed` | признак завершения раунда |

- Для завершённого раунда (10 ответов) `total = 10` и `correct + wrong = 10`.
- Для досрочного окончания (0 жизней) `total` равен числу отвеченных (например, 3), а не 10.
- `roundScore` не пересчитывается: он равен `correct × POINTS_BASE` только потому, что очки
  начисляются за каждый правильный ответ.

**Решение о `total`.** Знаменатель точности — **фактически отвеченные вопросы**
(`correct + wrong`). Для завершённого раунда это то же самое, что `TOTAL_QUESTIONS`; при
game over оценка всё равно «Игра окончена», а «0 из 10» при трёх ответах вводило бы в
заблуждение. Решение фиксируется комментарием в коде и тестом (0/3 → `total = 3`).

**Критерий готовности:** 8/2 → `correct = 8`, `wrong = 2`, `total = 10`, `roundScore = 80`.

---

#### TR-25. Оценка — из фактических счётчиков

- `lives <= 0` → 💔 «Игра окончена», проверка **раньше** точности;
- иначе `accuracy = Math.round(correct / total × 100)`, при `total = 0` — 0;
- пороги из `CONFIG.RATINGS`: 100 → 🏆, ≥ 70 → 🎉, ≥ 40 → 💪, < 40 → 📚;
- 8/2 → 80% → 🎉 «Отлично!»; 10/10 → 100% → 🏆 «Идеально!»; 0/3 → 💔 «Игра окончена».

**Критерий готовности:** три сценария дают три указанные оценки.

---

#### TR-26. Сброс раунда

`reset()` обнуляет **оба счётчика** вместе с остальными полями раунда (жизни, очки, индекс,
сложность, завершённость).

После `reset()`: `correct = 0`, `wrong = 0`, `total = 0`, `roundScore = 0`,
`lives = MAX_LIVES`, `completed = false`.

**Критерий готовности:** новый раунд не наследует счётчики предыдущего.

---

### 🔒 Совместимость

- Форма `GameResult` не меняется: `correct`, `wrong`, `total`, `roundScore`, `lives`,
  `completed`.
- Экран результатов, `useResults`, `GameRules.getRating` — без изменений API и разметки.
- Статистика (`Stats` v3), позиция на карте, звук, блокировка вкладок — не затрагиваются.

### 🚫 Что не входит

- Изменение порогов оценок, `POINTS_BASE`, `MAX_LIVES`, `TOTAL_QUESTIONS`.
- Показ точности, «из 10», новых карточек или строк на экране результатов.
- Изменение CSS и разметки.
- Изменение `Stats`, позиции, карты, звука, блокировки вкладок.
- Новые фичи (серии, бонусы, таймеры) и рефакторинг вне дефекта.

### 📝 Глоссарий — дополнения

| Термин | Значение |
|---|---|
| **Правильный ответ** | Ответ, совпавший с `answer`; +1 к счётчику правильных, +`POINTS_BASE` очков |
| **Неправильный ответ** | Ответ, не совпавший с `answer`; +1 к счётчику неправильных, −1 жизнь |
| **Отвечено** | `correct + wrong` — вопросы, на которые игрок ответил |
| **Точность** | `round(correct / total × 100)`, при `total = 0` — 0 |
| **Завершённый раунд** | 10 ответов, жизни > 0; `total = 10` |
| **Досрочное окончание** | 0 жизней до 10 вопросов; оценка «Игра окончена» |
