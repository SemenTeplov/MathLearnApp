## ⚛️ Этап 2. Первый React-компонент (пилот)

### Общая концепция

**Этап 2** — **пилот** интеграции React. **Цель** — **убедиться**, что React **работает** в проекте, **не сломав** существующую игру.

**Что делается:**

- **React** и **ReactDOM** — **устанавливаются** (если ещё нет)
- **Точка входа** — `main.tsx` (**React**-рендер)
- **Один** компонент — `ErrorModal` (**модалка** ошибок)
- **Остальное** — **старый** JS-код **работает** как раньше

**Что НЕ делается:**

- **Замена** View/Controller — **позже** (Этап 3)
- **Глобальное** состояние — **позже** (Этап 4)
- **Миграция** экранов — **позже** (Этап 3)

**Результат:** в проекте **сосуществуют**:

- **React**-приложение (`main.tsx` + компоненты)
- **Старый** JS-код (`view/*.js`, `controller/*.js`)
- **Гибрид** — оба **работают** через **Vite**

## 📋 Технические требования — Этап 2

### TR-7. Установить React и ReactDOM

**Требование:** установить **React** и **ReactDOM** (если ещё нет).

**Критерий готовности:**
- `react`, `react-dom` — в `dependencies`
- `@types/react`, `@types/react-dom` — в `devDependencies`

---

### TR-8. Создать точку входа `main.tsx`

**Требование:** создать **`main.tsx`** в **корне** проекта — **React**-рендер.

**Что должно быть:**

- **Импорт** React и ReactDOM
- **`root`**-элемент из HTML (`#root`)
- **Рендер** компонента `<App />`
- **Импорт** глобальных CSS-файлов

**Критерий готовности:**
- `main.tsx` создан
- React **рендерится** в `#root`
- **CSS** подключаются

---

### TR-9. Создать компонент `ErrorModal`

**Требование:** создать **первый** React-компонент — **модалку** ошибок.

**Что должно быть:**

- **Функциональный** компонент
- **Пропсы:** `title`, `message`, `onClose`
- **Разметка** — модалка с **заголовком**, **сообщением**, **кнопкой** «OK»
- **Стили** — **используют** существующие CSS-классы (`.modal-overlay`, `.modal`)
- **Типизация** — **полная** (`ErrorModalProps`)

**Критерий готовности:**
- Компонент **создан**
- **Пропсы** типизированы
- **Разметка** соответствует **CSS**
- **Рендерится** в браузере

---

### TR-10. Обновить `index.html`

**Требование:** обновить HTML — **добавить** `#root` и **подключить** `main.tsx`.

**Что должно быть:**

- **`<div id="root">`** — **перед** `</body>`
- **`<script type="module" src="/main.tsx">`** — **вместо** старого `script.js` **(временно)**
- **CSS** — **без** изменений

**Критерий готовности:**
- `<div id="root">` есть
- `main.tsx` **подключён** как **модуль**
- **Старый** `script.js` — **временно** **закомментирован** или **убран**

**Важно:** старый `script.js` **не удаляется** — **понадобится** позже.

---

### TR-11. Интегрировать `ErrorModal` со старым кодом

**Требование:** **показать**, что **ErrorModal** **работает** из **старого** JS-кода.

**Что должно быть:**

- **Глобальная** функция (например, `window.showErrorModal(title, message)`)
- **Старый** `ErrorView` — **вызывает** эту **функцию**
- **React**-**компонент** — **показывается** через **state** в `App`

**Критерий готовности:**
- **Старый** код **вызывает** `showErrorModal`
- **React**-модалка **появляется**
- **Кнопка** «OK» — **закрывает** модалку

---

### TR-12. Гибрид — старый JS продолжает работать

**Требование:** **старый** JS-код **продолжает** работать.

**Что должно быть:**

- **`view/*.js`** — **без** изменений
- **`controller/*.js`** — **без** изменений
- **`script.js`** — **без** изменений (или **адаптирован** минимально)

**Критерий готовности:**
- **Все** экраны работают (карта, игра, результаты)
- **Все** сценарии работают (победа, провал, глобальная карта)
- **Игра** — **играется** как раньше

---

### TR-13. `tsconfig.json` — поддержка `.tsx`

**Требование:** **`tsconfig.json`** должен **поддерживать** `.tsx`.

**Что должно быть:**

- `jsx: "react-jsx"` — **трансформация** JSX
- `include` — **включает** `*.tsx`
- `strict: true` — **оставлено**

**Критерий готовности:**
- `.tsx` файлы **компилируются**
- `npx tsc --noEmit` — **без ошибок** для `.tsx`

---

### TR-14. Игра работает

**Требование:** после **всех** изменений **игра работает**.

**Критерий готовности:**
- `npm run dev` — **запускается**
- **Карта** — **открывается**
- **Игра** — **играется**
- **Результаты** — **показываются**
- **Модалка** ошибок — **работает** через **React**
