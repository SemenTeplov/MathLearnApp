## ⚛️ Этап 3. Миграция экранов (по одному)

### Общая концепция

**Этап 3** — **замена** всех экранов на React **по одному**.

**Порядок миграции** — от **простого** к **сложному**:

| # | Экран | Сложность | Причина |
|---|-------|-----------|---------|
| 3.1 | **Экран результатов** | 🟢 Простой | Мало интерактивности |
| 3.2 | **Модалка выбора карты** | 🟢 Простой | Независима от игры |
| 3.3 | **Экран игры** | 🟡 Средний | Много состояния |
| 3.4 | **Карта предмета** | 🔴 Сложный | Игрок, движение, зоны |
| 3.5 | **Шапка** | 🟢 Простой | Иконка 🌍, счёт |
| 3.6 | **Экран приветствия** | 🟢 Простой | Удаляется (уже нет меню) |

**После каждого** экрана:

- **Старый** `view/*.js` — **удаляется**
- **Старый** `controller/*.js` — **удаляется** (или **превращается** в хук)
- **React**-компонент — **работает**
- **Игра** — **играется**

**После всех** экранов:

- **Старые** `view/*.js` — **удалены**
- **Старые** `controller/*.js` — **удалены**
- **`script.js`** — **удалён**
- **Всё** на React
