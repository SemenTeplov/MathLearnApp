## 🔧 Этап 1. TypeScript без React (типизация)

### Общая концепция

**Этап 1** — **внутренний** рефакторинг. **Пользователь** не видит **изменений**. Игра **работает** как **раньше**.

**Цель:** **типизировать** существующий JS-код. **Не** менять **архитектуру**. **Не** добавлять **React**.

**Что типизируется:**

- **Model** — `config`, `game-model`, `session-model`
- **Logic** — `generator`, `scoring`, `game-rules`
- **Storage** — `repository`, `local-repository`, `memory-repository`, `session-repository`
- **Service** — `stats-service`, `session-service`
- **Errors** — `custom-errors`, `error-handler`

**Что НЕ типизируется (пока):**

- **View** — `view/*.js` — **остаётся** JS
- **Controller** — `controller/*.js` — **остаётся** JS
- **Script.js** — **остаётся** JS

**Причина:** View и Controller **будут** **заменены** на React **на Этапе 2–3**.

## 📋 Технические требования — Этап 1

### TR-1. Создать `types.ts`

**Требование:** создать файл `types.ts` со **всеми** интерфейсами проекта.

**Обязательные типы:**

| Тип | Назначение |
|-----|-----------|
| `Problem` | Задача (question, answer, options, explanation) |
| `GameResult` | Результат раунда (correct, wrong, total, roundScore, lives, completed) |
| `MapData` | Данные одной карты (totalScore, currentTrainerIndex) |
| `Stats` | Общая статистика (version, currentMap, maps) |
| `SessionState` | Состояние раунда (lives, roundScore, currentQuestionIndex, difficulty, completed) |
| `ErrorInfo` | Информация об ошибке (action, userMessage) |
| `Rating` | Оценка (min, icon, title, subtitle) |

**Критерий готовности:**
- Все **7** типов созданы
- Типы **экспортируются** через `export`
- Нет **дублирования** с существующими JSDoc-типами

---

### TR-2. Переименовать простые файлы в `.ts`

**Требование:** переименовать **простые** файлы из `.js` в `.ts` **с** добавлением **типов**.

**Список файлов:**

| Было | Стало | Что типизировать |
|------|-------|-------------------|
| `model/config.js` | `config.ts` | `CONFIG` — тип `Config` |
| `logic/scoring.js` | `scoring.ts` | Функции — параметры и возврат |
| `logic/game-rules.js` | `game-rules.ts` | Функции — параметры и возврат |

**Критерий готовности:**
- Файлы **переименованы**
- Все **публичные** функции **типизированы**
- `npx tsc --noEmit` — **без ошибок** для этих файлов

### TR-4. Оставить View и Controller в `.js`

**Требование:** **не** типизировать View и Controller **на этом этапе**.

**Список файлов (остаются `.js`):**

- `view/*.js`
- `controller/*.js`
- `script.js`

**Причина:** будут **заменены** на React **на следующих** этапах.

**Критерий готовности:**
- View и Controller **не тронуты**
- Игра **работает** через них

---

### TR-5. Включить `allowJs` в `tsconfig.json`

**Требование:** `allowJs: true` — **позволяет** JS и TS **сосуществовать**.

**Критерий готовности:**
- `tsconfig.json` содержит `"allowJs": true`
- `tsc --noEmit` **не** падает из-за JS-файлов

---

### TR-6. Игра работает без изменений

**Требование:** после **всех** изменений — игра **работает** как **раньше**.

**Критерий готовности:**
- `npm run dev` — **запускается**
- Все **сценарии** (карта, игра, результаты, глобальная карта) — **работают**
- **Никаких** визуальных **изменений**
