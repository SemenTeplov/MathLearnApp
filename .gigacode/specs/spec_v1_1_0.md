## 🏆 Система очков и сохранение прогресса

### US-12. Общий счёт

**Как игрок**, я хочу **видеть свой общий счёт**, **чтобы** чувствовать прогресс между играми.

**Критерии приёмки:**
- Общий счёт начинается с 0
- После **успешного** раунда к общему счёту **прибавляются** очки, заработанные за раунд
- Общий счёт **сохраняется** между сессиями (даже после закрытия браузера)
- Общий счёт **отображается** в меню
- Общий счёт **никогда не уменьшается**

---

### US-13. Начисление очков за раунд

**Как игрок**, я хочу **зарабатывать очки за правильные ответы**, **чтобы** видеть свой результат.

**Критерии приёмки:**
- За **каждый правильный ответ** начисляется **10 очков**
- Очки **отображаются на лету** — сразу после ответа
- В конце раунда показывается **заработанная сумма**
- Очки начисляются в общий счёт **только** при **успешном завершении раунда**

---

### US-14. Условие успешного завершения раунда

**Как игрок**, я хочу **понимать, когда раунд считается успешным**, **чтобы** знать, когда очки будут зачтены.

**Критерии приёмки:**
- Раунд считается **успешным**, если:
    - Пройдены **все 10 вопросов**
    - Осталась **хотя бы 1 жизнь**
- Количество ошибок **не важно** — допускается несколько ошибок
- Раунд считается **провальным**, если:
    - Потеряны **все жизни**
    - Игрок **вышел** до завершения

---

### US-15. Сгорание очков

**Как игрок**, я хочу **быть предупреждён**, что мои очки сгорят при выходе, **чтобы** случайно не потерять прогресс.

**Критерии приёмки:**
- При попытке выйти во время раунда показывается **подтверждение**
- В подтверждении указывается **заработанная сумма**
- При согласии — выход в меню, очки **сгорают**
- При отмене — игрок **остаётся** в раунде
- Закрытие вкладки / обновление страницы **равнозначно** выходу — очки сгорают
- Провал раунда (0 жизней) — очки **сгорают**

---

### US-16. Сохранение прогресса между сессиями

**Как игрок**, я хочу, **чтобы мой общий счёт не терялся** при закрытии приложения.

**Критерии приёмки:**
- Общий счёт **сохраняется** автоматически после успешного раунда
- При следующем открытии приложения счёт **восстанавливается**
- Если данных **нет** — счёт начинается с 0
- Если данные **повреждены** — игрок видит **сообщение**, счёт начинается с 0
- Если хранилище **недоступно** — игрок видит **сообщение**, игра работает без сохранения

---

### US-17. Отображение счёта

**Как игрок**, я хочу **видеть счёт в разных местах**, **чтобы** всегда понимать свой прогресс.

**Критерии приёмки:**

| Экран | Что показывается | Где |
|-------|------------------|-----|
| **Меню** | Общий счёт | Наверху, по центру |
| **Игра** | Очки за текущий раунд | В шапке игры |
| **Игра** | Всплывающее «+10» | Угол экрана при каждом правильном ответе |
| **Результаты** | Заработано за раунд | В блоке статистики |

- Формат счёта в меню: «🏆 N»
- Формат счёта в игре: «🏆 N»
- Формат всплывающего: «+10»
- Формат на результатах: «Заработано: N»

---

### US-18. Ограничение одной сессии

**Как система**, я должна **предотвращать открытие нескольких вкладок** с игрой, **чтобы** избежать конфликтов данных.

**Критерии приёмки:**
- При попытке открыть **вторую** вкладку показывается **сообщение**
- Игра во **второй** вкладке **не запускается**
- Игра в **первой** вкладке **продолжается** без изменений

## ⚙️ Функциональные требования — дополнения

### FR-10. Хранение общего счёта

Система **обязана** сохранять общий счёт между сессиями.

**Что сохраняется:**
- Общий счёт (`totalScore`)
- Версия формата данных

**Что НЕ сохраняется:**
- Очки текущего раунда (сгорают при выходе)
- Серия (не используется)
- Промежуточное состояние игры

**Когда сохраняется:**
- После **успешного** завершения раунда
- При обнулении (повреждённые данные, миграция)

**Когда загружается:**
- При старте приложения

**Обработка ошибок:**
- Данных нет → счёт 0
- Данные повреждены → сообщение + счёт 0
- Хранилище недоступно → сообщение + работа в памяти

---

### FR-11. Обновление общего счёта

После **успешного** завершения раунда система **обязана**:
totalScore += заработано за раунд

**Если обновление не удалось:**
- Очки **не зачитываются**
- Игрок видит **сообщение** об ошибке
- Общий счёт **не меняется**

**Если раунд провален:**
- Общий счёт **не меняется**
- Заработанные очки **сгорают**
- Игрок видит **результаты раунда** (заработано, но не зачтено)

---

### FR-12. Версионирование данных

Система **обязана** хранить **версию** формата данных.

**При загрузке:**
- Версия **совпадает** → использовать как есть
- Версия **старше** → мигрировать (добавить недостающие поля с дефолтами)
- Версия **новее** → обнулить + сообщение

**Если миграция упала:**
- Обнулить + сообщение
- Продолжить работу со счётом 0

---

### FR-13. Отображение счёта

Система **обязана** отображать счёт:

| Где | Что | Формат |
|-----|-----|--------|
| Меню (над логотипом) | Общий счёт | «🏆 190» |
| Игра (шапка) | Очки за раунд | «🏆 50» |
| Игра (угол) | Всплывающее | «+10» |
| Результаты | Заработано за раунд | «Заработано: 50» |

**Поведение:**
- Счёт обновляется **мгновенно** при правильном ответе
- Всплывающее «+10» показывается **1.5 секунды**
- Анимации счёта **не используются**

## 🎯 Критерии успеха — дополнения

Система считается **успешной**, если:

1. Игрок **видит общий счёт** в меню
2. Счёт **растёт** после успешного раунда
3. Счёт **не теряется** при закрытии браузера
4. Очки **сгорают** при выходе во время раунда
5. Игрок **предупреждён** о сгорании очков
6. При **повреждённых данных** — сообщение и сброс
7. При **недоступном хранилище** — сообщение и работа в памяти
8. Вторая вкладка **блокируется**

## 📝 Глоссарий

| Термин | Значение |
|--------|----------|
| **Сессия** | Одна игра из 10 вопросов |
| **Серия (streak)** | Правильные ответы подряд |
| **Лучшая серия** | Максимальная серия за игру |
| **Точность (accuracy)** | Процент правильных ответов |
| **Жизни (lives)** | 3 попытки, −1 за ошибку |
| **Оценка (rating)** | Сообщение на экране результатов |
| **Точность** | `(правильных / всего) × 100%` |

---

## 📝 Глоссарий — дополнения

| Термин | Значение |
|--------|----------|
| **Общий счёт** | Сумма очков за все успешные раунды |
| **Очки за раунд** | `10 × правильных ответов в текущем раунде` |
| **Успешный раунд** | Все 10 вопросов пройдены, жизни > 0 |
| **Провальный раунд** | Потеряны все жизни или игрок вышел |
| **Сгорание** | Очки за раунд **не зачитываются** в общий счёт |
| **Версия формата** | Номер структуры данных для миграции |
