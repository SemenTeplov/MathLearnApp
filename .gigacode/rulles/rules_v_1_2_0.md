## 🏛️ Архитектурные принципы — дополнения

### A15. Звук — отдельный слой

**Звуковое сопровождение** — **отдельный** инфраструктурный слой.

**Структура:**

- **Папка** `js/audio/` — модуль звука
- **Папка** `audio/` в корне — файлы звуков
- **Сервис** `AudioService` — управление звуком

**Правила:**

- Controller — **единственный**, кто вызывает `AudioService.play()`
- View **не** играет звук
- Logic **не** играет звук
- Model **не** знает о звуке
- Звук — **некритичная** функция, ошибки **игнорируются**

### A16. Предзагрузка звуков

**Правило:** звуки **предзагружаются** при старте приложения.

**Правила:**

- `AudioService.preload()` вызывается **один раз** при инициализации
- Предзагрузка **не блокирует** запуск приложения
- Если предзагрузка упала — игра **продолжается**

### A17. Обработка ошибок звука

**Правило:** ошибки звука **не ломают** игру.

**Правила:**

- Все операции со звуком — в `try/catch`
- Ошибки **логируются** в `console.warn`
- Игрок **не уведомляется** (некритичная функция)
- Если звук недоступен — игра работает **без** него

## 🔧 Технические ограничения — дополнения

### T13. Звук — локальные файлы

- Звуки — **локальные** MP3-файлы в `audio/`
- **Не** использовать CDN
- **Не** использовать base64 в JS
- Формат — **MP3** (универсальная поддержка)

### T14. Звук — только через AudioService

- **Прямое** использование `new Audio()` **запрещено** вне `AudioService`
- **Прямое** использование `AudioContext` **запрещено** вне `AudioService`
- Controller вызывает **только** `AudioService.play()`
- View **не** управляет звуком

## ✅ Обязательства агента — дополнения

При работе со **звуком** агент **обязан**:

1. **Создать** `AudioService` с методами `preload()` и `play()`
2. **Предзагружать** звуки при старте
3. **Вызывать** `play()` **только** из Controller
4. **Обрабатывать** ошибки звука через `console.warn`
5. **Не ломать** игру при ошибке звука
6. **Использовать** локальные MP3-файлы
