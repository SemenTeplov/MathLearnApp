## 🏛️ Архитектурные принципы — дополнения (1.5.0)

### A29. Глобальная карта

**Правило:** глобальная карта — **выбор** предмета.

**Правила:**
- Иконка 🌍 **фиксирована** в углу
- Видна **только** на карте
- Модалка со **списком** карт
- **Текущая** карта **выделена**

### A30. `Stats` версии 3

**Правило:** данные **хранятся** по картам.

**Структура:**

```javascript
{
    version: 3,
    currentMap: 'math',
    maps: {
        math: {
            totalScore: 0,
            currentTrainerIndex: -1
        }
    }
}
```

**Правила:**
- currentMap — текущая карта
- maps — объект с данными по картам
- Каждая карта — свои totalScore и currentTrainerIndex
- Миграция 2 → 3

### A31. Выбор карты

**Правило:** выбор карты — сброс позиции.

**Правила:**

- currentTrainerIndex = -1
- totalScore сохраняется
- Без подтверждения
- Без сброса при выборе той же

## 🔧 Технические ограничения — дополнения (1.5.0)

Иконка 🌍 фиксирована (position: fixed)
Позиция — верхний правый угол
Видна только на карте (#mapScreen)
Модалка — кастомная (как ErrorView)

### T25. Stats — версия 3

Структура: currentMap + maps
Миграция 2 → 3
Доступ к данным — через currentMap:

``` javascript
const currentData = stats.maps[stats.currentMap];
```
