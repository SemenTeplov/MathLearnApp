## 🏛️ Архитектурные принципы — дополнения

### A18. Карта — главный экран

**Правило:** карта — **главный** и **единственный** экран выбора.

**Правила:**

- **Меню отсутствует** — нет экрана с логотипом и кнопкой «Начать игру»
- При загрузке приложения **сразу** открывается карта
- Карта **содержит** зоны и тренажёры
- Зоны **не кликабельны** — только визуальные блоки
- Тренажёры **кликабельны** — вызывают модалку сложности

### A19. Зоны и тренажёры — данные в конфиге

**Правило:** зоны и тренажёры **описываются** в `CONFIG`.

**Правила:**

- Зоны — массив объектов в `CONFIG.ZONES`
- Каждая зона: `id`, `title`, `color`, `trainersCount`
- Тренажёры **не** описываются отдельно — их количество задаётся в зоне
- Названия тренажёров — **номер** (1, 2, 3, 4, 5)

### A20. Карта — отдельный view и controller

**Правило:** карта — **отдельный** view и **отдельный** controller.

**Правила:**

- `view/map-view.js` — отрисовка карты
- `controller/map-controller.js` — обработка кликов
- `ScreenView` **знает** о карте как об экране
- Карта **не содержит** бизнес-логики

### A21. Сложность — через модалку

**Правило:** сложность **выбирается** через **модальное** окно.

**Правила:**

- Модалка **появляется** при клике на тренажёр
- Модалка **содержит** три кнопки сложности
- Модалка **содержит** кнопку «Отмена»
- После выбора — **старт** игры
- Сложность **не сохраняется** между играми

## 🔧 Технические ограничения — дополнения

### T15. Карта — стилизация

- **Зоны** — блоки разного цвета
- **Цвета** — из `CONFIG.ZONES[i].color`
- **Тренажёры** — по пути (змейка)
- **Соединения** — линии между тренажёрами
- **Дизайн** каждой зоны — **позже**

### T16. Генератор задач — без изменений

- Генератор **не знает** о зонах и тренажёрах
- Генератор **не фильтрует** по теме
- Тема — **позже**
- Сейчас — **смешанный** генератор (как есть)

### T17. Игра — без изменений

- Экран игры **не меняется**
- Логика игры **не меняется**
- Жизни, очки, вопросы — **как есть**
- Тема **не передаётся** в игру

## ✅ Обязательства агента — дополнения

При работе с **картой** агент **обязан**:

1. **Создать** `map-view.js` и `map-controller.js`
2. **Убрать** меню из HTML
3. **Добавить** разметку карты в HTML
4. **Описать** зоны в `CONFIG.ZONES`
5. **Реализовать** отрисовку зон с цветами
6. **Реализовать** отрисовку тренажёров по пути
7. **Реализовать** клик на тренажёр → модалка сложности
8. **Изменить** кнопку «В меню» на «На карту» в результатах
9. **Не менять** логику игры
10. **Не менять** генератор задач
