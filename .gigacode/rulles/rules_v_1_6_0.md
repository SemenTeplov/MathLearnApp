## 🏛️ Архитектурные принципы — дополнения (1.6.0)

### A32. TypeScript — постепенная миграция

**Правило:** переход на TypeScript — **постепенный**.

**Правила:**

- **Сначала** — Model, Logic, Storage, Service, Errors
- **Потом** — View и Controller (на Этапах 2–3, при переходе на React)
- **`allowJs: true`** — позволяет JS и TS **сосуществовать**
- **Каждый** файл — **отдельно**, без «большого взрыва»

### A33. Типы — в `types.ts`

**Правило:** все **общие** типы — в **одном** файле.

**Правила:**

- **Один** файл `types.ts`
- **Все** интерфейсы **экспортируются**
- **Нет** дублирования типов
- **Нет** `any` без **крайней** необходимости

### A34. Строгий режим

**Правило:** `tsconfig.json` — **строгий** режим.

**Правила:**

- `strict: true`
- `noEmit: true` (проверка **без** компиляции)
- `skipLibCheck: true` (быстрее проверка)

### A35. View и Controller — пока JS

**Правило:** View и Controller **не** типизируются **на Этапе 1**.

**Причина:** будут **заменены** на React.

**Правила:**

- View и Controller — **`.js`**
- **Не** трогать их **на Этапе 1**
- Игра **работает** через них

## 🔧 Технические ограничения — дополнения (1.6.0)

### T26. TypeScript — конфигурация

**`tsconfig.json`** должен содержать:

```json
{
  "compilerOptions": {
    "target": "ESNext",
    "lib": ["DOM", "DOM.Iterable", "ESNext"],
    "module": "ESNext",
    "moduleResolution": "Node",
    "jsx": "react-jsx",
    "strict": true,
    "allowJs": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "noEmit": true
  },
  "include": ["src"]
}
```

## Ключевые параметры:

- strict: true — строгая типизация
- allowJs: true — JS и TS вместе
- noEmit: true — не компилировать (Vite сам)

### T27. Типизация — правила

Все публичные функции — типизированы
Все классы — с полями и методами
Все интерфейсы — в types.ts
any — только в крайних случаях
unknown — предпочтительнее any

### T28. Проверка типов

npx tsc --noEmit — обязательно перед коммитом
Нет ошибок — критерий готовности
Ошибки — исправить или осознанно any + комментарий
