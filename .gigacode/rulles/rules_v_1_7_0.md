## 🏛️ Архитектурные принципы — дополнения (1.7.0)

### A36. React — постепенная интеграция

**Правило:** React **внедряется** **постепенно**, **не** заменяя **всё** сразу.

**Правила:**

- **Сначала** — **один** компонент (пилот)
- **Потом** — **экраны** по одному (Этап 3)
- **Старый** JS **работает** **параллельно**
- **Удаление** старого — **только** после **полной** миграции (Этап 5)

### A37. Гибрид — React + старый JS

**Правило:** React **и** старый JS **сосуществуют** **на** Этапе 2.

**Правила:**

- **React-файлы** — `.tsx` **с** `import`/`export`
- **Старые JS-файлы** — `.js` **без** модулей
- **Связь** — через **глобальные** функции (`window.*`)
- **Vite** **собирает** всё **вместе**

### A38. Точка входа — `main.tsx`

**Правило:** **React**-**рендер** — **в** `main.tsx`.

**Правила:**

- **`main.tsx`** — **в** **корне** проекта
- **Импортирует** `<App />` и **глобальные** CSS
- **Рендерит** в **`#root`**
- **Не** содержит **бизнес-логики**

### A39. Первый компонент — `ErrorModal`

**Правило:** первый компонент — **модалка** ошибок.

**Причина:** простая, независимая, легко проверить.

**Правила:**

- **Функциональный** компонент
- **Пропсы:** `title`, `message`, `onClose`
- **Типизация** — полная
- **CSS** — **существующие** классы

### A40. Связь — через `window`

**Правило:** **связь** React и **старого** JS — через **`window`**.

**Правила:**

- **Глобальная** функция `window.showErrorModal(title, message)`
- **Старый** код **вызывает** её
- **React** **рендерит** модалку
- **После** Этапа 3 — **уберём** `window`

**Причина:** **временное** решение, **пока** старый код не мигрирован.
